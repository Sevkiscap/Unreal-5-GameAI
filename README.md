##About
 This is a project utilizing Unreal Engine 5's behavior tree to experiment and deep dive into new implementations of GameAI.This project focuses on exploring and experimenting with Unreal Engine 5’s Behavior Tree system. By diving into the engine’s GameAI decision making. The project's vision is to prototype with new implementations for best practices used in GameAI development.

##Requirements
The project requires you to have Unreal Engine 5.5.4 or newer installed.

##Running
To test the project in your own domain, you have to download Unreal Engine 5, then run the AIDeneme2.uproject with Unreal Engine 5.
